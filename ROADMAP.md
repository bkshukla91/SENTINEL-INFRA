# Roadmap
1. Live collectors (PIB, NHAI, state portals RSS, news APIs) with de-duplication.
2. NER/LLM extraction with human review queue, measured on a labelled set.
3. Geospatial layer (PostGIS, OSM) for real routes, bridge load class, terrain.
4. Alerting on budget changes and delays; change history per project.
5. Access control, audit logs, and secure deployment.
